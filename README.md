# DiCoSTEM-TT

Competencia Digital y Educación STEM en la Formación del Profesorado.
Proyecto de investigación de la Universidad de Extremadura PID2022-140601OA-I00.

La web reúne los objetivos, el equipo, las publicaciones, las contribuciones a congresos y los recursos educativos del proyecto. Está disponible en español, portugués europeo e inglés.

[Visitar la web de DiCoSTEM-TT](https://dicostem-tt.github.io/)

[Consultar los recursos educativos](https://dicostem-tt.github.io/es/recursos/)

[Abrir H5PDF](https://dicostem-tt.github.io/h5pdf/?lang=es)

## Contenido del repositorio

- `es/`, `pt/` y `en/` contienen las páginas de cada idioma.
- `_data/` contiene los datos compartidos de equipo, resultados y otros contenidos.
- `_includes/` y `_layouts/` contienen las plantillas de Jekyll.
- `assets/` contiene los estilos, scripts e imágenes.
- `h5pdf/` contiene el conversor de PDF a H5P y su ayuda.

## Mantenimiento

El sitio se publica con Jekyll en GitHub Pages desde la rama `main`. Para proponer una corrección o mejora, abre una incidencia o una solicitud de cambios en este repositorio. Las consultas al equipo se pueden enviar desde la página de contacto de la web.

Para trabajar en local, instala las dependencias con `bundle install` y ejecuta `./serve-local.sh`. La copia generada en `_site/` se excluye del control de versiones.
